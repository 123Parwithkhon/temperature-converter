# 🌡️ Temperature Converter

A clean and responsive real-time bidirectional temperature converter web application. Users can input values in either Celsius or Fahrenheit to automatically receive instant converted results rounded to two decimal places.

## 🚀 Features
* Bidirectional real-time conversion (Celsius ⇄ Fahrenheit)[cite: 24, 25].
* Automatic rounding of results to two decimal places (`toFixed(2)`)[cite: 25].
* Clean card interface styled with Google Fonts (Roboto Mono) and focus animations[cite: 23, 24].

## 🛠 Technologies Used
* **HTML5** (Number input fields, semantic labels)[cite: 24]
* **CSS3** (Flexbox alignment, absolute centering, custom input states)[cite: 23]
* **JavaScript** (Mathematical conversion formulas, dynamic event handlers)[cite: 25]

## 💻 How to Run
1. Clone or download this repository.
2. Open `index.html` in any web browser[cite: 24].

# 🌡️ Конвертер температуры

Удобное и понятное веб-приложение для мгновенного двустороннего перевода температуры между градусами Цельсия и Фаренгейта. При вводе значения в любое из полей результат автоматически рассчитывается и округляется до двух знаков после запятой.

## 🚀 Особенности
* Двусторонний перевод в реальном времени (Цельсий ⇄ Фаренгейт)[cite: 24, 25].
* Автоматическое округление результатов до двух знаков после запятой[cite: 25].
* Лаконичный интерфейс с фокусом на полях ввода и моноширинным шрифтом[cite: 23].

## 🛠 Используемые технологии
* **HTML5** (поля ввода чисел `number`, метки `label`)[cite: 24]
* **CSS3** (выравнивание Flexbox, центрирование, стилизация полей)[cite: 23]
* **JavaScript** (математические формулы перевода, обработка событий `oninput`)[cite: 24, 25]

## 💻 Как запустить
1. Клонируйте или скачайте этот репозиторий.
2. Откройте файл `index.html` в любом веб-браузере[cite: 24].
